# Prueba Técnica – UNIPAGO

Proyecto realizado como parte de una prueba técnica para el proceso de selección de Desarrollador de Software en UNIPAGO.

## Descripción

Se desarrolló una API sencilla utilizando Python y FastAPI para gestionar una lista de animes.

La aplicación permite:

- Ver todos los animes registrados.
- Buscar un anime por su ID.
- Agregar nuevos animes.
- Modificar la información de un anime.
- Eliminar un anime.

## Tecnologías utilizadas

- Python
- FastAPI

## Cómo ejecutar el proyecto

**1. Instalar las dependencias:**

```bash
pip install -r requirements.txt
```

**2. Iniciar la aplicación:**

```bash
fastapi dev main.py
```

**3. Probar la API:**

Abrir en el navegador:

http://127.0.0.1:8000/docs

Desde ahí se pueden probar las diferentes funciones de la aplicación.

## Nota

Los datos se almacenan temporalmente en una lista, por lo que se reinician al detener y volver a ejecutar la aplicación.
